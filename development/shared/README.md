# Shared development notes

Place publication-safe development proposals, ADR drafts, implementation plans,
and review notes here. Use descriptive subdirectories as the material grows.

Before committing a new file, run the publication allowlist and redaction tests
and add the file explicitly to `PUBLICATION_ALLOWLIST.json`.

The active formal-release map is under [`release-wayfinder/`](release-wayfinder/map.md).
