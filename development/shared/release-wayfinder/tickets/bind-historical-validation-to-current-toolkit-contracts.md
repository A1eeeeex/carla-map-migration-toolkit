## Question

For each Primary Profile, which recovered historical artifacts prove a real
stage or check, which are only characterization, and which current-toolkit
stages must be replayed to produce a sanitized, hash-traceable Verified Run
without copying private assets or inventing evidence?

## Resolution

Recovered records confirm historical validation signals for all three Primary
Profiles. Against the current 41 required checks, historical relevance binds as
15 direct, 20 partial and 6 no-match. Because no record satisfies the complete
current workspace, stage provenance, exact stack, rights-safe input,
redaction/signoff and Verified Run contract, all 41 checks still require current
evidence. The resulting minimum stage bundles are documented in the
[public-safe binding summary](../../release-research/historical-evidence-binding-summary.md).
