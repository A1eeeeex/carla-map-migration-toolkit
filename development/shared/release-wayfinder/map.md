## Destination

The repository is safe to make public, installs from a clean clone, and has a
current-toolkit Verified Run for one Primary Profile on each of the three
migration routes at its required evidence level. It presents a rights-cleared
demonstration and is ready to tag `v0.1.0-rc` after explicit release
authorization.

## Notes

- The 2026-09-05 working Goal first closes source-distribution readiness using
  existing evidence, one targeted installation/demo check and one scoped
  final text scan. Do not rerun engines, all profiles or full history/log audits
  merely for documentation and packaging edits. See the
  [current release checklist](../../../docs/release-readiness.md).
- Selecting a final public release label does not block local source preparation.
  The source candidate is documented as experimental; this map's strict RC
  destination is not waived or marked achieved by source-distribution checks.
- The source-candidate closeout passed 22 targeted checks, isolated Plugin
  installation on CLI 0.153.4 and the anonymous L1 demo. The 11-case routing
  smoke and eight small historical-record hash checks passed. A 191-file
  source-only candidate is frozen locally with rollback to the pre-closeout
  snapshot. No engines were restarted and no remote write was performed.
- The resumed local Goal packages that checked source into a deterministic
  archive with neutral owner/time metadata, checksums and a file manifest.
  Installation/tests are reused for unchanged bytes; actual publication and
  the strict three-route RC destination remain separate, unmet gates.

- This map carries execution through the release gates, not only planning.
- Use `implement`, `tdd`, and `code-review` for product changes; preserve the
  route-specific CARLA/Unreal safety rules in `AGENTS.md`.
- Historical private evidence may guide characterization but cannot be
  relabelled as a current-toolkit Verified Run.
- Customer maps, private XODR, Unreal/CARLA binaries, engine files and private
  logs never enter the public candidate.
- Public visibility, remote pushes and GitHub Releases require a final explicit
  authorization after the release audit.

  separate from the documented contract.

  legal attribution identifies the verified individual copyright holder,
  `@A1eeeeex` is the public maintainer, and original public-candidate material
  uses Apache-2.0 with a separate private vulnerability-reporting gate.
- [Choose the first current-toolkit verified route](tickets/choose-first-current-toolkit-verified-route.md):
  no single route is the release anchor; v0.1 route coverage requires one
  accepted Primary Profile on all three routes, while secondary Profiles may
  remain explicitly experimental.
- [Bind historical validation to current-toolkit contracts](tickets/bind-historical-validation-to-current-toolkit-contracts.md):
  recovered evidence confirms historical validation across all three routes;
  its relevance to the current 41 required checks is 15 direct, 20 partial and
  6 no-match, while all 41 still require current-contract evidence.
- [Freeze the three Primary Profile stacks](tickets/freeze-three-primary-profile-stacks.md):
  exact RoadRunner R2025a, integration bundle 1.4.4, CARLA 0.9.16, Source Unreal
  4.26.2, Package client/server and vanilla Unreal 4.27.2 identities are locked;
  observed dirty environments remain unaccepted.
- [Implement current execution-context evidence adapters](tickets/implement-current-context-evidence-adapters.md):
  a Python 3.7-compatible external context finalizer and host recorder now bind
  Source Unreal, UE4.27 Unreal, CARLA client and shell receipts to sealed
  stage/version/hash/backup/rollback/redaction contracts, including all three
  routes' repair and guarded optimization stages. The accepted UE4.27 target
  receipt also passed the later strict completeness/acceptance recorder replay.
- [Supply and approve the authoritative private literal set](tickets/supply-authoritative-private-literal-set.md):
  the owner approved a 60-entry normalized set derived from all 19 hash-verified
  original sources plus the two private planning inputs; plaintext and approval
  evidence remain Git-ignored.
- [Mirror and audit every private GitHub ref](tickets/mirror-and-audit-private-github-refs.md):
  authenticated connector and SSH enumeration found one branch and no tags,
  pull-request or other advertised refs; the exact-match mirror's 187 reachable
  objects passed the approved private-literal and prohibited-binary-path audit.
- A current Source→UE4.27 target-validation stage was replayed in real UE4.27.2
  through the current context adapter. The first candidate was withdrawn after
  strict log review found material errors. A bounded eight-texture Unreal-API
  repair and fresh replay then passed all six stage checks plus five fixed-view
  reviews; the context-finalized, sensitive-term-scanned stage candidate remains
  private pending complete-route L5 evidence.
- A rights-safe L1 quickstart, explicit Python 3.10 installation path and

  isolated Plugin install/list and the full test suite. Three independent
  ephemeral sessions also discover the correct Plugin-qualified Skill for one
  canonical prompt per route. Exact-commit replay remains open.

## Out of scope

- Publishing or redistributing any customer, private, CARLA, Unreal or
  RoadRunner binary asset.
- Verifying every secondary Profile before the first release candidate;
  `roadrunner-filmbox`, `generic-fbx-xodr`, `full-carla-package` and `hil-ready`
  may remain explicitly experimental.
- Expanding the toolkit into a general Unreal platform, OpenDRIVE editor or map
  asset repository.
