## 0.1.0 — Experimental first release

This source release is experimental, not an accepted strict v0.1.0-rc.
The entries below summarize its development history; current evidence and
limitations are described in `docs/current-status.md`.

- Prepared a deterministic source-only distribution with checksums and neutral
  archive metadata; documented installation from its repository-root folder.
- Separated completed local-source preparation from strict RC acceptance and
  explicit authorization to publish the existing GitHub repository.

- Refreshed release/installation guidance for the observed CLI 0.153.4 model
  compatibility boundary and documented the bounded 11-case routing smoke.
- Recovered later Source driving and second-project sunny Content-delivery
  records without rerunning engines or promoting them to complete Verified Runs.
- Added a proportional release checklist separating source distribution,
  strict RC verification and permission-gated GitHub publication.

- Integrated route-scoped Content delivery and profiling workflows from a local
  Skill review without adding a fourth route or redistributing source assets.
- Added guarded `map-package-audit`, `content-audit`, `delivery-manifest` and
  diagnostic `compare-metrics` commands; hardened archive regular-file checks.
- Made strict performance comparison report optional-counter regressions and
  missing/invalid values alongside the existing frame-time/protection gates.
- Added producer/receiver, import/Cook troubleshooting and staged performance
  references, delivery-only routing cases and a plain-language capability list.
- New diagnostic reports do not replace stage receipts or upgrade L3–L5 claims.

- Confirmed and documented historical validation for all three routes, plus
  repair and optimization evidence, without copying private sources or assets.
- Added context-bound receipt finalization and guarded stage/check evidence
  recording for Source Unreal, UE4.27 Unreal, CARLA client and shell-build.
- Bound repair and optimization apply evidence across all three routes and
  corrected RoadRunner material/reference audits to the Source Unreal
  post-import stage.
- Added a rights-safe L1 quickstart and a version-bounded Plugin installation
  contract using the repository-local Python 3.10 environment.
- Required complete stage receipts with explicit PASS/FAIL acceptance binding,
  blocked next-stage progress after failure, and extended publication audit to
  forbidden historical asset paths and unscannable binary content.
- Aligned hosted and local test commands with the publication clean-tree
  contract by disabling bytecode writes, third-party pytest autoload and the
  pytest cache provider.
- Corrected installed Skill examples to use Plugin-qualified names and verified
  all three routes in independent ephemeral Codex sessions.

- Added one skills-only Plugin with exactly three migration-route Skills.
- Added deterministic host inspection, planning, plan verification, archive
  safety, backup manifest, redaction, status aggregation, and performance checks.
- Added six versioned JSON contracts, anonymous examples, profile catalog,
  static trigger/behavior evaluation data, and L0–L2 tests.
- Recorded all real Editor/runtime/cold-copy work as `NOT_RUN`.
- Consolidated future development material under `development/`, with a tracked
  publication-safe area and a Git-ignored local/private area.
- Initialized the reviewed source tree in a private GitHub repository; no public
  release or visibility change was made.
- Added Phase A claims, non-claims, support-status, acceptance, proof and
  claim-to-evidence contracts.
- Added Claims Registry and Verified Run schemas; compatibility verification now
  requires a verified-run ID and evidence path.
- Hardened verified evidence gates so sparse PASS records, fabricated run
  references, empty dependency facts and invalid required-check aggregation
  cannot signal success.
- Versioned the breaking Phase A evidence/plan contracts as 1.1.0 and documented
  regeneration; Verified Run references now require schema-valid, rehashed
  artifacts and an exact environment fingerprint.
- Versioned the semantic evidence and executable-plan gates as 1.2.0: stale
  plans are rejected, Package verification requires L5, typed stage/redaction
  artifacts are schema-checked inside each run bundle, and proof levels remain
  L0–L5.
- Versioned the executable route-plan contract as 1.3.0 and the redaction report
  as 1.1.0. Dependency actions reject empty executable fields; Verified Run
  checks bind to catalog stages and underlying hashed evidence; input and
  structured artifact bytes are read once; redaction coverage binds exact paths
  and hashes plus a private sensitive-term-set fingerprint.
- Versioned Verified Run as 1.3.0 and route-plan as 1.4.0. Every required check
  now cites structured, non-empty check evidence bound to its run, route, stage
  and check ID; route plans require the complete ordered stage catalog; public
  evidence paths are normalized repository-relative paths; and redaction also
  scans the Verified Run and redaction-report envelopes directly.
- Versioned check-evidence as 1.1.0, Verified Run as 1.4.0 and route-plan as
  1.5.0. Required checks now bind to proof-capable evidence types and an exact
  positive acceptance observation; route stages bind catalog type, execution
  context and risk, reject broad path targets, and bind read/write/backup paths
  to the fingerprinted workspace.
- Added Source CARLA → UE4.27 dependency classification that blocks unknown,
  unsupported or undefined replacement actions before plan execution.
- Added an original text-only Golden Map plan with eight fault variants; no map,

- Revalidated the private 17-script inventory and historical baseline locally;

- Selected a verified individual copyright holder and accountable maintainer,
