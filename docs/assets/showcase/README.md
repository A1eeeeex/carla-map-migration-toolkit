# Showcase media slots

Two maintainer-authorized, anonymized scene captures illustrate the
[UE4.27 migration case](../../cases/source-carla-to-ue427.zh-CN.md).
They are unmodified pixels from historical captures, not downloadable map assets.
The before/after views span several repairs, not a single-variable experiment.
Both PNGs contain only IHDR/IDAT/IEND chunks, without textual or EXIF metadata.
Display permission does not grant redistribution rights for underlying maps,
textures, OpenDRIVE or project files.

Only these exact paths and reviewed SHA256 values are exempted from binary
publication restrictions in the audit tool. Altered or additional images require
new review; fixtures remain text-only. Future rights-cleared media may be proposed here
after the [capture checklist](../../../development/shared/plans/golden-map/CAPTURE_CHECKLIST.md)
and evidence review. Keep raw captures and maps outside the repository.

Use stable names such as `source-runtime-overview.png` and
`ue427-cold-copy-pie.png` only when those views actually exist. Every caption must
identify its route/profile/stack and link to reviewed evidence; a screenshot
alone cannot prove migration success. Update the exact publication allowlist and
media policy before adding files: all other map-media binary restrictions remain.

with reviewed views and case-specific results; leave unavailable routes explicit.
