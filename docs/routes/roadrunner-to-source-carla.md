# RoadRunner to Source CARLA

Use the `roadrunner-to-source-carla` Skill. The public implementation currently
proves host-only inventory, path safety, plan, schema, and fixture contracts.
Dataprep, Source Editor, CARLA runtime, and traffic/navigation checks are
`NOT_RUN` until a real authorized replay supplies evidence.

Recovered historical records do show real post-import material/reference/save
and validation signals for this route. `NOT_RUN` above means they are not yet a
current-contract L4 Verified Run. Current material/reference Editor evidence is
bound to `RR2SRC.POST_IMPORT_AUDIT`, not the CARLA-client target stage.
