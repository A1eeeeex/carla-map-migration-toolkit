# Source CARLA to Package CARLA

Use the `source-carla-to-package-carla` Skill. The public implementation includes
archive inspection that never extracts input and blocks traversal, links,
duplicates, and oversized declarations. Real Cook, import, runtime, and rollback
replay are `NOT_RUN`.

Planning requires explicit, in-root Source handoff, asset inventory, dependency
manifest, route manifest, and XODR files. Their sizes and SHA-256 values are
sealed into the plan and rechecked before it can verify.
