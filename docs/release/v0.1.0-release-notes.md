# v0.1.0 — Experimental Public Preview

These notes describe the v0.1.0 Experimental Public Preview.
Publication and tag checks are tracked in the [release checklist](github-settings-checklist.md).

## What this is

A Codex Plugin plus reusable host-side CLI tooling for custom CARLA map workflows.
The Plugin includes three route Skills with shared scripts, JSON schemas, reason
codes and structured validation/evidence contracts.

## Three routes

- RoadRunner → Source CARLA: input inspection, import checkpoints and repair guidance.
- Source CARLA → Package CARLA: Cook/build guidance, archive audit and runtime handoff.
- Source CARLA → vanilla UE4.27: dependency/action planning and clean-project delivery guidance.

## Observed primary stack

RoadRunner R2025a, CARLA 0.9.16, Source Unreal 4.26.2 and vanilla Unreal 4.27.2.
The installation rehearsal used Ubuntu 22.04 x86_64, Python 3.10.12 and Codex CLI
0.153.4. These are observed/tested scopes, not a compatibility guarantee.

## Host automation and engine work

Host tooling inspects declared workspaces, generates/verifies sealed plans,
audits archive/Content/named-map layouts, emits SHA256 delivery manifests,
compares performance summaries and validates/records supplied stage receipts.
Dataprep Import/Execute/Commit, asset repairs, Cook/import, CARLA runtime, PIE
and cold-copy still require authorized external tools and real checks.

## Verification boundary

Historical real-use records exist for all three routes with case-specific coverage.
Complete current-contract end-to-end Verified Runs are not available for all routes.
Hosted CI and synthetic fixtures are not engine tests. `validate` creates a pending
NOT_RUN report; performance diagnostics are not proof of accepted optimization.
Commit-bound results are in [current status](../current-status.md).

The [historical UE4.27 case](../cases/source-carla-to-ue427.md) includes
authorized before/after captures, bounded sky/material repairs and rollback of
an LOD candidate that did not improve end-to-end performance. Screenshots show
appearance, not performance or compatibility across maps and versions.

## Installation and limitations

Install the complete Plugin using the [installation guide](../installation.md).
There is no standalone PyPI distribution. Start with the
[engine-free script example](../../demo/quickstart/README.md) and
[troubleshooting cookbook](../troubleshooting/README.md).
See [known limitations](../../KNOWN_LIMITATIONS.md) before real operations.

## Golden Map

No downloadable public Golden Map is included. The historical case shares
authorized screenshots, not map assets. The
[onboarding framework](../../development/shared/plans/golden-map/README.md)
defines future rights, inputs, route checkpoints, evidence and capture requirements.
Maintainer-provided assets remain external to Git until any separate public sharing
is explicitly reviewed. This release includes neither customer maps nor engine binaries.
